# 科研图表通用指导

本文件只规定跨软件通用的科学与视觉原则，不给出具体 API、命令或模板。确定使用 Python 或 PGFPlots 后，再读取对应技术指南。

## 1. 先确定图要回答的问题

绘图前用一句话写清图的核心结论，并说明每个面板提供什么证据。没有独立证据作用的面板应删除或移入补充材料。图形类型由问题决定，不因已有模板方便而选择。

## 2. 保持数据可追溯

明确源数据、变量、单位、时间基准、工况、筛选条件和统计方法。不得为了美观或渲染方便静默删除数据。降采样、异常值处理、聚合和插值必须有科学理由，并保留原始数据与处理记录。

## 3. 建立视觉层级

一张图应有明确的主要证据和辅助证据。颜色、线型、标记、透明度和面板尺寸用于表达层级，不用于装饰。避免所有面板等权、颜色过多、图例反复和无意义的网格线。

## 4. 保持项目一致性

同一论文中的相同对象、工况和模型应尽量保持稳定色序、线型、名称、单位与面板顺序。新图优先适应既有论文规范；只有既有规范妨碍识读时才局部调整，并说明原因。

## 5. 保证可识读性

图应在最终插入尺寸下可读，而不是只在放大屏幕上清晰。检查字体、线宽、标记、误差棒、图例、色条和标签。不得仅依靠红绿区分；考虑灰度打印和常见色觉差异。

## 6. 图形应体现不确定度

实验和统计结果应说明样本数、重复定义、中心量、离散量或置信区间。模型图应说明训练/验证划分、误差定义、基线与不确定度。误差棒和阴影区的含义必须在图注中明确。

## 7. 图注与正文分工

图注说明图中对象、工况、变量、统计定义和必要方法；正文负责解释现象、定量比较、机制证据和结论边界。不要在正文逐点复述曲线，也不要让图注承担整段讨论。

## 8. 交付前审核

- 核心结论是否明确，每个面板是否服务该结论？
- 图中数值、单位、工况和图例是否与源数据一致？
- 数据排除、降采样和统计处理是否可追溯？
- 颜色和线型是否与全文一致且易于区分？
- 图在最终尺寸下是否可读，无裁切、遮挡和乱码？
- 正文中的关键数字是否可以从数据复算？
- 源数据、绘图代码、输出文件和论文引用是否能对应？

图表的最高优先级是清晰、可靠地支持科学论证；美观服从这一目标。
