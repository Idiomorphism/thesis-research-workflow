# 行文风格与论证组织

## 1. 总体风格

采用凝练、克制、可核验的中文科技写作。作者偏好信息密度高的连续论述，不接受口号式、宣传式或教科书式铺陈。语气应有判断力，但结论强度必须受证据约束。

本论文正文的统计特征可作为软参考：中文句长中位数约 43 字，四分位区间约 29—58 字，说明作者并非一味追求短句，而是在中等句长内完成条件、数据和结论的连接。不要机械追求该数字；当一句承担两个以上主要判断时应拆分，当连续短句造成碎片化时应合并。

## 2. 段落逻辑

结果分析段优先采用：

`对象与条件 → 主要现象 → 关键数值 → 机制证据/替代解释 → 有边界的结论`

理论段优先采用：

`现有假设 → 失效条件 → 缺失物理量 → 推导或建模选择 → 适用条件`

方法段优先采用：

`任务目标 → 输入与边界 → 方法选择理由 → 实施过程 → 输出与验证方式`

综述段优先采用：

`领域问题 → 方法谱系 → 代表性证据 → 局限比较 → 尚未解决的具体问题`

## 3. 句式偏好

- 先写研究对象和条件，再写动作或判断，避免悬空结论。
- 一句话只承担一个主判断；限定条件、数据和因果链可服务该判断。
- 适度使用“因此”“由此”“然而”“需要说明的是”，但每个连接词都应对应真实逻辑关系。
- 谨慎使用“显著”“明显”“极大”“全面”等强词；有统计检验、数量级差异或明确对比时再使用。
- 避免“不是……而是……”“不仅……更是……”“既……又……”的模板化堆叠。
- 避免隐喻、拟人、价值宣传和“填补空白”式自我评价，除非检索和证据确实足以支撑。

## 4. 摘要和创新点

摘要应面向贡献组织，减少研究过程叙事。每项贡献依次回答：解决的缺口、提出的方法或能力、关键证据、适用意义。关键数字用于证明贡献，不能堆成结果清单。

创新点以新知识或新能力开头，例如“构建……模型”“阐明……机制”“提出……决策方法”。不要以“研究了”“开展了”“采用了”开头。验证结果作为可信度证据，不把验证层级本身强行拔高为创新。

## 5. 文献综述

综述应从广义研究问题逐步收敛到本文缺口，不按后续章节标题机械分类。引用必须基于摘要、全文、可靠笔记或数据库字段核验，不能只依据题名推测内容。段落既要呈现进展，也要比较假设、工况、评价量和局限；最后形成可被本文研究链条响应的具体缺口。

## 6. 图表说明

写图前先回答“这张图证明什么”。正文不要逐点复述曲线，应识别阶段、峰谷、转折和工况差异，再用关键数值锚定。机制解释须联合压力、质量、温度、界面面积、分解项或其他独立量；单图证据不足时保留替代解释。

图形风格强调可识读性和项目一致性：统一色序、线宽、字号、单位、图例和采样密度；避免色彩相近导致曲线与背景混淆。美观服务于数据区分，不能牺牲信息准确性。

## 7. LaTeX 源码表达

论文正文可在源文件中按中文句号一行一句，以便版本比较；句间不额外插入空段。符号、单位、引用和标签遵循项目原 Skill。修改文本时保留作者已有命令、标签和数据路径，除非任务明确要求调整。

## 8. 答辩与幻灯片

幻灯片比论文更高层：一页围绕一个问题或结论，标题直接表达信息，不用冒号堆叠。页内保留能支撑结论的最少方法细节，页与页之间形成“问题—方法—证据—解释—贡献”的推进。备份页承载推导、敏感性、额外图表和可能被追问的边界条件。
