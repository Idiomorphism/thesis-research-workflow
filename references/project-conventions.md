# 项目约定、术语与学术边界

## 1. 文件操作边界

将本工作区视为博士学位论文项目。默认只读；只有用户在当前轮次明确授权具体范围后，才可删除、修改、覆盖、复制或重命名文件。授权不得从上一轮自动延续，也不得从一个文件扩张到同目录其他文件。

执行写入前：

1. 解析目标文件的绝对路径与授权范围。
2. 检查工作区现有改动；用户已有内容不得覆盖或回退。
3. 大幅修改优先使用用户指定副本；用户要求保留原稿时采用 `-1` 等明确副本。
4. 只讨论、只审核、只给方案或只读任务不得产生外部写入。
5. 写入后重新读取目标位置并检查差异，不能仅相信工具返回成功。

## 2. 学术诚信与证据

不得编造数据、参考文献、公式、标签、工况、实验条件或结论。区分：文件中读取的数值、图表直接呈现的趋势、由方法链作出的推断、尚未验证的解释。数据文件、硬编码表格、图中结果与用户描述不一致时，报告差异，并以用户明确指定或经核验的源数据为准。

不得帮助规避学术诚信或 AIGC 检测；可通过恢复作者真实论证、核验引用、保存研究过程证据、减少模板化表达来降低误判风险。

## 3. 项目结构

- 主文件：`seuthesiY.tex`
- 章节：`chapter/`
- 数据：`data/`
- 图像：`figures/`
- 参考文献库：`config/seuthesiY.bib`
- 项目 Skill：`skills/`

除非用户明确要求，不改动既有标签、引用键、数据路径、章节输入顺序、图表环境和模板宏包。项目使用 SeuThesiY，优先复用已有命令和样式，不另建平行规范。

## 4. 通用术语

研究对象：低温流体、液氢、液氮、蒸发气、气相、液相、气液界面、有限尺寸体系、饱和温度、饱和压力。

热质传输：热质传输、相变传热、蒸发通量、冷凝通量、温度梯度、速度梯度、压力响应、容器相对压力、漏热、黏性耗散、自增压、热分层。

模型与验证：数值模拟、分子动力学模拟、连续介质模型、力场模型、边界条件、初始条件、网格无关性、离散化误差、不确定度、验证、标定。

动载与工程应用：动载环境、晃荡、充满率、任务剖面、液氢燃料贮箱、液氢罐箱、蒸发气管理、主动泄放、风险评估、GIS 空间分析、费马模糊集。

## 5. 专项术语与符号

### 分子动力学

优先使用：气液平衡模拟、虚拟真空模拟、双边界标定、液相边界、气相边界、密度剖面、高密度液相平台、界面厚度、自发蒸发分子数 `$N_{\mathrm{sp}}$`、跨界面蒸发分子数 `$N_\mathrm{evap}$`、相变系数 `$\sigma$`、蒸发通量 `$J_\mathrm{evap}$`。

有限尺寸体系液相平台收窄时写“高密度液相平台显著收窄”，除非数据直接支持，不写“蒸发殆尽”。相变系数是概率型比例参数时，不将其等同于绝对蒸发通量。

### CFD 与 GCI

优先使用：正弦激励、振幅、角频率、自然对流、气液界面形态、网格收敛指数（Grid Convergence Index, GCI）、表观阶数 `$p$`、Richardson 外推、渐近区、渐近比值、细网格、中网格、粗网格、三元组、压力离散化不确定度。

符号必须沿用局部定义，不随意改写上下标、正斜体和单位，如 `$P_{\mathrm{rel}}$`、`$GCI_{12}$`、`$N_\mathrm{evap}$`、`$N_\mathrm{sp}$`、`$\sigma$`。

## 7. 引用规范

正文使用 `\cite{key}`，引用键必须存在于 `config/seuthesiY.bib`。不得虚构键或根据题名臆测文献结论。需要文献而尚未找到时明确标记缺口；只有用户允许时才插入占位引用。

学位论文条目保留模板需要的 `type={[博士学位论文]}` 或 `type={[硕士学位论文]}`。检查误写的 citation，如 `\cite{，}`、自然语言被放入 citation 键或键前后混入中文标点。引用必须直接支持相邻主张。
